YOUR LITTLE UNIVERSE — atualização interativa

1. No GitHub, abra o repositório Cybervi-sos.
2. Substitua os arquivos index.html, style.css e script.js pelos arquivos deste pacote.
3. Dentro de assets, substitua the-library.png e the-soundroom.png pelos arquivos deste pacote.
4. Faça Commit changes. O GitHub Actions fará o deploy automaticamente.
5. Abra https://cybervi-sos.github.io/Cybervi-sos/

Esta versão amplia a cena para ocupar a largura disponível, inclui brilho/efeitos de hover nos livros,
mensagens ao clicar, troca de dimensão e estrelas animadas. Os livros já têm áreas de clique,
mas os destinos Gmail/GitHub/LinkedIn ainda precisam ser configurados com os links corretos.
